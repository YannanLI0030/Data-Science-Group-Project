# Ablation gene panels

This directory contains the gene panels used in the dynamic ablation study and
their multi-omics extracts. It does not contain relevance judgements. Candidate
pools and Gold standards are stored separately under `benchmarks/`.

## Unfiltered random panel

Files beginning with `ablation_100genes_unfiltered_random_` come from the
panel supplied by a teammate. The genes were sampled uniformly from the DepMap
RNA columns after excluding 22 genes that had already been used or inspected.
The NumPy seed was 42. We kept this panel unchanged because its naturally
sparse evidence coverage is useful for testing:

- missing modalities and data-source coverage;
- scoring failures, ties, and ranking collapse;
- Top-10 overlap across frozen configurations;
- whether Confidence varies enough to affect ordering.

The panel has no independently verified relevance labels. It is a missing-data
stress test, not an independent performance benchmark, so NDCG, Recall, and MRR
are not reported for it.

## Coverage-stratified panel

Files beginning with `ablation_100genes_coverage_stratified_` were generated by
`scripts/export_coverage_stratified_ablation_panel.py`. Sampling used only
pre-model coverage information and a fixed seed. The strata cover reliable
low, intermediate, and high RNA--Protein correlation; Protein availability
without a reliable correlation estimate; multi-source RNA without Protein;
and DepMap RNA alone.

The long table includes only DepMap IDs found in the matching local
`9_DepMap_sample_info.csv`. Historical IDs removed during this check, together
with the affected row counts, are recorded in the manifest.

This panel makes component interventions observable under different evidence
conditions. It still has no relevance labels. A separate 12-gene subset was
subsequently frozen and reviewed for V5 before NDCG, Recall, and MRR were
calculated.

## File map

- `*_list.csv`: selected genes and their coverage fields;
- `*.parquet`: long-format evidence for those genes;
- `*_coverage_catalog.csv`: eligible genes and stratum assignments;
- `*_manifest.json`: thresholds, seeds, hashes, provenance, and audit counts.

The blank V5 reviewer file, completed review and exported Gold are kept
separate from `candidate_pool_v4_review.csv`. See
`docs/v5_holdout_evaluation.md` for their roles and interpretation limits.

## Regenerating the panel locally

AWS is not required. From the repository root, run
`python scripts/export_coverage_stratified_ablation_panel.py --help` and supply
the local raw-data directory and RNA--Protein correlation file. The frozen
random-panel list and seed are recorded in the panel manifest.

Existing panel files are protected from accidental replacement. Use `--force`
only when intentionally regenerating the same version. Add
`--verify-input-hashes` to compare the local inputs with
`data_manifest/manifest.json`.
