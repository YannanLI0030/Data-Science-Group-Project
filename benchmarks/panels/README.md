# Ablation gene panels

This directory stores **gene panels and derived multi-omics extracts**, not
relevance judgements. Candidate pools and gold standards remain separate under
`benchmarks/`.

## `ablation_100genes_unfiltered_random_*`

The teammate-generated panel was sampled uniformly from DepMap RNA gene
columns after excluding 22 previously used or inspected genes, with NumPy seed
42. It is retained unchanged for missing-data stress testing.

Appropriate uses:

- data-source coverage and missingness;
- scoring success/failure under sparse evidence;
- score ties and ranking collapse;
- Top-10 overlap/rank stability across frozen configurations;
- whether confidence varies enough to affect ranking.

It has no independently verified relevance labels, so it must not be described
as an independent performance test and must not be used to report NDCG,
Recall, or MRR.

## `ablation_100genes_coverage_stratified_*`

Generated by `scripts/export_coverage_stratified_ablation_panel.py`. Selection
uses only pre-model coverage information and a fixed seed. The default strata
include reliable low/mid/high RNA-protein correlation, protein without a
reliable correlation estimate, multi-source RNA without protein, and DepMap
RNA-only genes. The generated long table is restricted to DepMap IDs present
in the matching local `9_DepMap_sample_info.csv`; removed historical IDs and
row counts are retained in the manifest audit.

This panel is for controlled component ablation and coverage-stratified
robustness. A separately frozen 12-20-gene subset must be independently judged
before final NDCG/Recall/MRR evaluation.

## File roles

- `*_list.csv`: selected genes plus selection/coverage fields.
- `*.parquet`: unified long-table evidence extract for those genes.
- `*_coverage_catalog.csv`: eligible universe and stratum assignments.
- `*_manifest.json`: provenance, thresholds, seeds, hashes, and audit counts.

Do not append V5 holdout judgements to `candidate_pool_v4_review.csv`. Reuse its
column schema in a separate `candidate_pool_v5_holdout_review.csv` after the
configurations and V5 genes are frozen.

## Local regeneration

AWS is not required. From the repository root, run:

```bash
/Users/liyannan/miniconda3/envs/cellline-v3/bin/python \
  scripts/export_coverage_stratified_ablation_panel.py \
  --data-dir "/Users/liyannan/Desktop/cellline_selector_v3/data_s3" \
  --corr "/Users/liyannan/Desktop/Data Science MSc Graduation Project/gene_rna_protein_correlations.csv" \
  --exclude-file "benchmarks/panels/ablation_100genes_unfiltered_random_list.csv" \
  --seed 42
```

The command refuses to overwrite existing panel files. Add `--force` only when
deliberately regenerating the same version. Add `--verify-input-hashes` when a
full local verification against `data_manifest/manifest.json` is required.
